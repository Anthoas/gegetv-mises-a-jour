# GégéTV : mises à jour

Ce dépôt public ne sert qu'à distribuer l'application GégéTV (Android TV) à ses utilisateurs.
L'application n'y contient **aucun identifiant ni abonnement** : chaque télé garde les siens.

Au démarrage, GégéTV lit `version.json` (dernière publication) ; si une version plus récente existe,
elle propose de l'installer.
